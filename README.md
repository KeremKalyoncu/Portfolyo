## 📋 Hakkında

Kişisel projelerimi ve yeteneklerimi sergilediğim tek sayfalık portfolyo sitesi.
Video arka plan, müzik ve görsel medya öğeleriyle zenginleştirilmiş bir tasarıma sahiptir.

## ✨ Özellikler

- 🎬 Tam ekran video arka plan
- 🖼️ Medya galerisi
- 📱 Duyarlı (responsive) yerleşim
- 🎨 Özel CSS animasyonları

## 🚀 Çalıştırma

Herhangi bir derleme adımı gerekmez:

```bash
git clone https://github.com/KeremKalyoncu/Portfolyo.git
```

Ardından `index.html` dosyasını tarayıcıda açmanız yeterlidir.

## 📁 Yapı

```
Portfolyo/
├── index.html      # Ana sayfa
├── style.css       # Stil tanımları
└── Medya/          # Video, müzik ve görseller
```
